# evidence Specification

## Purpose

Run state is gitignored, so what the scripts measured is invisible to
everyone judging what to build next. This is the committable render of
it — relayed, never recomputed.

## Requirements


### Requirement: Run evidence is committable and rendered, never recomputed
`bin/routine-evidence` SHALL print a snapshot suitable for committing:
a header naming the generating script, the moment it was taken, and the
corpus the snapshot derives from,
followed by `bin/routine-retro`'s output **verbatim**. It SHALL NOT
recompute any measurement — a second derivation of the same number can
drift from the first, so the snapshot relays the retro rather than
reimplementing it. The repository SHALL carry the rendered snapshot at
`evidence/retro.txt`, regenerated by that script and never edited by
hand, so a reviewer or a council reads measurements instead of assuming
them. Freshness SHALL be decided wherever the declared corpus is present
and SHALL NOT be claimed where it is absent: `runs/` is absent in CI, so
no check running there can prove the snapshot current, while a machine
holding the corpus can decide it and SHALL — that machine is where a
stale snapshot is committed in the first place. Where the corpus is
absent the header's timestamp remains the honest statement of when the
snapshot was true.

#### Scenario: The body is the retro, byte for byte
- **WHEN** `routine-evidence` and `routine-retro` run over the same
  corpus
- **THEN** the snapshot's body equals the retro's output exactly

#### Scenario: The snapshot says what made it
- **WHEN** the snapshot is read
- **THEN** its header names the generating script and the time it was
  taken, and states that it is generated

#### Scenario: Committed evidence exists
- **WHEN** the repository is checked
- **THEN** `evidence/retro.txt` exists and carries the generator header

#### Scenario: The snapshot names the corpus it came from
- **WHEN** the snapshot is read
- **THEN** its header declares the corpus the body derives from, so a
  check can tell a stale render from one it cannot judge

#### Scenario: An empty corpus is declared as absent
- **WHEN** `routine-evidence` runs where no telemetry exists
- **THEN** its header declares the corpus absent, so a checkout that
  can regenerate nothing says so rather than rendering a body that
  looks like a measurement
