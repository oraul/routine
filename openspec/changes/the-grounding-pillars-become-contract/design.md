# Design — the-grounding-pillars-become-contract

## The motto is one sentence, chosen against two rivals

Kept: "Evidence tries to kill the claim; what survives is knowledge."
Rejected: "A claim is held by what failed to refute it, not by what
agreed with it" — truer to the mechanism, but two clauses where one
will do; and "Refute first; what survives, ships" — punchier, but it
drops the word *evidence*, which is the word doing the work. Recorded
so the next debate starts from the reasons, not the slogans.

## Pillars are vocabulary; obligations are contract; rails are earned

Three layers with deliberately different strengths. The pillar names
land in `project.md` so records and retros can cite them. The
obligations land in the analyst's contract because that is where this
loop's recorded incidents happened. The rails — a refutation line
form, road coverage, per-question approval — are each their own
change with their own red: this change adds no script, so nothing in
it can pretend a name is an enforcement. `project.md` says exactly
that, and a pin holds the sentence.

## Where each obligation lands

Refutation, symmetry, and the confound rule go under the analyst's
Rules — they govern how grounding is produced. `approve.md` goes in
Re-entry beside the sources already listed there. Probe provenance
extends the #95 forecast bullet rather than adding a second bullet
about the same distinction — one rule, one home, no drift pair.

The refutation attempt records as an Evidence bullet, not a new
grounding section: the attempt is an execution against the target,
which is exactly what Evidence holds, and a new section would need a
lint change this change refuses to smuggle in. That forces two
consequences the first draft missed: the Evidence definition widens
in the same edit (one bullet per file read **or probe executed** —
otherwise the contract carries two irreconcilable accounts of the
bullet, the drift pair this repository refuses), and the quoted
command with its decisive output lives **inside the one-line claim**,
because `routine-spec-lint` feeds every non-blank Evidence line
through `^- [^[:space:]]+ — .+` and a fenced block would burn a
counted revise at the gate.

Two scopes keep the new rules from contradicting the old: a
load-bearing claim that is a forecast is never probed in advance —
its refutation is the grader it already names, and an obligatory
pre-implementation probe of unwritten code would recreate exactly the
simulation incident this change cites — and `approve.md` is read
**when present**, because `routine-approve` writes it only when a
note is given and re-entry legitimately precedes approve on the
lint-revise road. The skill's surviving-record payload gains the
matching `approve.md` line (the template already exceeds the spec'd
three-file list — `characterize.log` set the precedent), so the
fourth source is passed by the driver, not remembered by the agent.

## An adversarial panel ran before apply

Four independent reviewers attacked the committed proposal — delta
completeness, pin absence, contract drift, citation truth — and
returned twenty findings, eight blocking; every blocker is fixed in
this revision (measured — the panel's greps and diffs are quoted in
its findings). Kept at full fidelity, per the symmetric-recording
pillar this change lands: the panel **refuted one of this design's
own claims** — `kill` was asserted absent from `project.md`, and
`grep -qi 'kill'` already passes there because `skills` contains the
substring. It also refuted two exhibit citations (the simulation
incident is #95's analyst-clause motivation, not its founding
exhibit; the omitted-attempts count was two developers omitting one
each, not one omitting two). The corrections stand above; the
original wrong claims are recorded here.

## Pins

Pin words verified absent at HEAD (measured — the greps ran, twice:
once before the first draft, once by the adversarial panel):
`survives`, `knowledge` absent from `CLAUDE.md` and `project.md`;
`kill` absent from `CLAUDE.md` but present in `project.md` only as
the substring of `skills`, so the motto pin word-bounds it with
`grep -qiw`; `refute`, `inconvenient`, `fidelity`, `curated`,
`quotes`, `approve.md`, `binds`, `confound`, `variable` absent from
`analyst.md`; `approve.md` absent from `skills/routine/SKILL.md`; the
seven pillar names and `never a gate` absent everywhere. The
`approve.md` pins use `grep -F` — the #92 lesson: a regex dot matches
any character and can bless a file the pin should redden.
