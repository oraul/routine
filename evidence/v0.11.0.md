# Release record: v0.11.0

Compared against v0.10.0. The range is the five merges in
`v0.10.0..HEAD` — the grounding-pillars program, C1 through C5, landed
in one day. Nothing outside it is credited here.

## Caffeine

- **The evidence discipline is named contract, not habit.** The
  lifecycle motto — evidence tries to kill the claim; what survives is
  knowledge — and seven grounding pillars sit beside the Laws, with
  five analyst obligations pinned by tests (#98). An adversarial panel
  attacked the proposal before apply and found eight blockers — a fake
  red pin (`kill` already matched `skills`), two miscited exhibits,
  and wording the gates would have refused — so the change practiced
  the pillar it shipped, and the refutations are kept at full fidelity
  in its archived design.

  evidence: the motto and obligation pins in `test/guidance_content.bats` and `test/agents_content.bats`, each shown red on words verified absent first; the panel's refuted claims quoted in the archived design of #98.

  lives in: `CLAUDE.md`, `openspec/project.md`, `agents/analyst.md`

- **The repo's own gate verdicts record in every clone.** Capture had
  depended on an accident: a failed scaffold created `runs/routine` on
  2026-08-15, and the whole tree was gitignored, so every fresh clone
  silently dropped release and convention verdicts until the accident
  repeated (#99). Grounding the fix refuted its own design-time
  premise first — 27 of 28 roads were walked, not 25, and two release
  gates had recorded — and what survived was worse than what was
  refuted.

  evidence: `git ls-files runs/` names exactly the shipped marker; the pre-proposal measurement — the find/cut union over every telemetry file — is quoted in #99.

  lives in: `runs/routine/README.md`, `.gitignore`

- **Every road a contract opens is declared and judged, and the check
  counts itself.** `routine-road-check` refuses an undeclared road
  that fired, a declared road nothing walked, and a stale waiver; its
  first live run truthfully reported its own road unwalked, walked it
  by running, and passed from the second run on — the bootstrap
  settled exactly as the design predicted (#99).

  evidence: both live runs quoted in #99 — exit 1 naming `harness.roads`, then exit 0 at 29 declared; at this record's writing the live verdict is 30 declared, 2 waivered, exit 0.

  lives in: `lib/roads.txt`, `bin/routine-road-check`

- **The proceed is earned per question and binds what it blessed.**
  One word used to lift every open question at once, and a proceed
  could predate the amendment it approved with nothing comparing the
  clocks. Each non-floor question now takes its numbered answer or
  nothing records; every proceed fingerprints exactly what the
  operator was shown; the audit refuses a conclude whose artifacts
  moved after the last proceed; and the lint checks every question's
  provisional reading (#100).

  evidence: ticket 0006 parked on four questions — one word would have answered all four; ticket 0005's approval predates its requirement amendment, a conclude the fingerprint rule now makes impossible. The task's red also caught mawk treating an all-zeros fingerprint as numeric false — the emptiness test is string, never truthiness.

  lives in: `bin/routine-approve`, `lib/approve.sh`, `bin/routine-audit`, `bin/routine-spec-lint`

- **One claim is always re-run, and nobody chooses which.** Both lints
  name a sampled claim per run — the index derived from the file's own
  bytes, so verification cannot be steered toward convenient claims —
  and the analyst's trust rule lifts its prohibition without losing
  its default (#101).

  evidence: the sample line on every lint run; this record's final lint named its own sample, and the pull request that landed the record states which entry it was and what re-ran.

  lives in: `bin/routine-spec-lint`, `bin/routine-record-lint`, `agents/analyst.md`

- **The confound instrument exists.** `routine-replay` holds an
  archived requirement byte-identical against a detached worktree at
  the archived anchor, so the requirement and the target stand still
  and only the rails differ (#102). Built and tested; never run — the
  Gate says what that costs.

  evidence: all four archived shopapp anchors measured reachable before proposing; the refusal roads proven to create nothing lasting, including the empty container a first honest red caught.

  lives in: `bin/routine-replay`

- **The replay ran, and the abort became a conclude.** Archived ticket
  0002 — the byte-identical requirement against the same target commit
  — aborted at its conclude gate because a pure-characterization task
  was jointly unsatisfiable under those rails. Replay ticket 0007
  concluded clean: the characterization pin went through
  `routine-tdd characterize` (its first live run, closing the v0.9.0
  Gate entry that said the phase had only ever met fixtures), the
  feature took every red before any green, and the audit — including
  the new fingerprint rule, also on its first live pass — blessed the
  record. One variable moved between the two runs, and it was the
  rails.

  evidence: 0002's `abort.md` names the structural refusal; 0007's telemetry carries `tdd.characterize [5103540e]`, three matched red/green pairs, and `ticket.conclude`; the suite closed at 8 runs, 9 assertions, 0 failures, re-run by the driver before concluding. The run also refuted one of the instrument's own choices — the preflight refused its detached worktree — fixed in #104 before this release.

  lives in: `runs/shopapp/tickets/archive/0007`, `bin/routine-replay`

- **The pillars are re-scored, and six of seven moved.** Scored at
  the program's design; re-scored here against the rails this release
  built. A score is a judgment anchored to the cited evidence, and
  nothing is a 5 until a script decides it. Provenance 3→4
  (fingerprints and quoted probes; the anchor is still regex-checked,

  Freshness 3→4 (rulings are read, and a stale approval cannot

  the developer's mirror is still queued). Confound honesty 2→4 (the
  instrument ran: the archived abort became a clean conclude with
  requirement and target held still, so the cause is the rails' — one
  data point, with the serving model's vintage the named residual
  confound). Exercised roads 2→4
  (declared and judged both directions; the check stays a session
  instrument by design, because run evidence is session-local).

  evidence: each movement names its merged rail in the entries above; the two pillars short of 4 name the missing rail and its earning condition rather than rounding up.

  lives in: this record — re-scored at each release, because a score that never moves is a decoration

## Gate

- **One replay is one data point.** The abort-to-conclude verdict
  above rests on a single controlled run, and the replay can hold the
  requirement and the target still but not the serving model's
  vintage — the residual confound is named, not removed.

  evidence: exactly one `ticket.replay` line exists in any telemetry, and the archived pair 0002/0007 is the only controlled comparison on record.

  script that would decide it: more replays — 0003 and 0005 have reachable anchors and verbatim requirements waiting; each run either strengthens or breaks the attribution.

- **The sampled spot-check has no teeth and has caught nothing yet.**
  It reports and never gates — the designed boundary, since truth
  stays a judgment — but until a sampled re-run catches a shipped
  false claim, the mechanism's value is itself a prediction.

  evidence: the final lint of this record named one sampled entry, re-verified before publishing and recorded in the landing pull request rather than here, because editing this file to quote its own sample would move the bytes that choose it.

  script that would decide it: none until the first catch; the earning condition is recorded in #101.

- **Nothing gates a delta's carry-completeness, and it silently
  dropped a line once already.** A modified requirement's delta must
  carry the live text verbatim, and C4's delta lost the final line of
  a carried scenario to an off-by-one range; a hand diff caught it
  before sync, and only habit demanded that diff.

  evidence: the correcting commit in #101 restores the dropped line in its diff and describes the off-by-one in its message — re-verified when this record's own lint sampled this entry, which also caught this line saying "quotes" where the message only describes.

  script that would decide it: the queued `routine-change-check` — a delta's carried requirement matching the live spec byte-for-byte outside its stated additions.

- **A session URL arrives in every pull request footer, and a hand
  scrubs it every time.** Five pull requests this release, five
  read-backs, five scrubs. A hard rule held by vigilance is the kind
  of rule that eventually fails.

  evidence: every body in #98–#102 was read back after creation and edited; two also needed placeholder text rewritten after the host swallowed angle brackets.

  script that would decide it: the queued `routine-pr-body-check` — the footer scrub as an exit code.
