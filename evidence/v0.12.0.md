# Release record: v0.12.0

Compared against v0.11.0. The range is the four merges in
`v0.11.0..HEAD` — the approve seam hardened both ways, then two
hand-held rules became exit codes, all in one evening. Nothing
outside it is credited here.

## Caffeine

- **A standing ruling stands until the operator moves it.** The
  per-question gate built in the last release re-demanded every
  question on every re-approve: ticket 0008's three re-approvals
  typed twelve answers of which exactly two carried an operator
  judgment, the rest filler re-affirming rulings already on the
  record. The gate now reads the ruled marker the 0008 reconciliation
  had invented ad hoc — a ruled bullet no longer blocks unanswered,
  its entry line says the ruling stands, and answering it anyway is
  how the operator moves the ruling (#106).

  evidence: the four entries of the archived 0008 `approve.md`, filler counted against genuine moves; the two new refusal tests shown red on the untouched gate, with the third new test honestly labelled green at birth because answering by index was already baseline behavior.

  lives in: `bin/routine-approve`, `agents/analyst.md`, `skills/routine/SKILL.md`

- **The marker earned its trust, and a ruling is probed before it is
  baked.** The gate above lifts its refusal on a marker's word, so
  the marker's citation became a lint: a ruled bullet naming an
  answer no `approve.md` entry records fails at the analyst gate,
  before it can lift anything. The semantic half — the 0008 A2
  collision, a correctly cited ruling that could not be built against
  the requirement's literal signature — stays a judgment by design,
  so it became the analyst's obligation to run the probe that would
  kill an override before baking it, and to return a refuted ruling
  with the probe quoted (#107).

  evidence: exactly four lint tests red on the untouched script and the pass-case labelled a characterization; the A2 amendment on 0008's record, discovered mid-build when a reconciliation probe of keyword defaults would have caught it three proceeds earlier.

  lives in: `bin/routine-spec-lint`, `agents/analyst.md`

- **The scrub is an exit code, and it caught its prey on its first
  day.** Seven pull requests had shipped only because a hand read
  each body back and removed the injected session URL — the one hard
  rule held by vigilance alone. `routine-pr-body-check` refuses a
  saved body naming line and pattern class, never echoing the match,
  and its first two live runs each caught the injection on the very
  pull requests that shipped and followed it (#108, #109). The
  sensitive shapes now live once, in a library both hunts source.

  evidence: the refusal `line 28: session URL` exit 1 on the fetched body of #108, then `clean` exit 0 after the scrub it demanded, repeated on #109; the change itself was refused twice by its own rails before push — the proposal for quoting the pattern it describes, the new tests for naming what they hunt — both fixed on record.

  lives in: `bin/routine-pr-body-check`, `lib/sensitive.sh`, `bin/routine-convention-check`

- **The carry is gated before every sync.** A modified requirement's
  delta once lost a line silently and only a habitual hand diff
  caught it; the habit ran before every sync since, unforced.
  `routine-change-check` walks every live line of a modified
  requirement and fails the first one the delta lost, by capability,
  requirement, and text; a requirement the delta claims to modify
  that the live spec does not hold fails the same way (#109). Its
  first pre-sync run blessed its own change's carry.

  evidence: all eight tests red on the script's absence, then green; the named boundary — a lost line surviving inside an unrelated line can escape, so the check hunts the incident class and the author's diff stays the finer instrument; the `harness.change` road walked live, road-check at 33 declared, 1 waivered.

  lives in: `bin/routine-change-check`

## Gate

- **The body check runs at the right moment only by discipline.** The
  scrub is decided by script, but nothing forces the script to run
  after each pull request is created — the invocation itself is the
  remaining habit, and the habit is the failure mode the script was
  built to end.

  evidence: both live catches this release happened because the driver chose to save the body and run the check.

  script that would decide it: a CI job running `routine-pr-body-check` over the pull request body the workflow event already carries, failing the board a leaked body ships on.

- **The ruling probe has never met a live override.** The
  reconciliation obligation landed with its pins, but no epic with an
  operator override has run since; the claim that the probe catches
  an unbuildable ruling at reconciliation is a prediction resting on
  a reconstruction of 0008.

  evidence: no ticket since 0008 carries an override, so no reconciliation has had a ruling to probe.

  script that would decide it: none — the next epic whose approve overrides a provisional settles it either way.

- **The carry check is a net, not a proof.** Byte-exactness outside a
  delta's stated additions is not decidable while the additions are
  undeclared, so a coinciding line can escape the substring rule. The
  queued `routine-change-sync` would make the sync mechanical and the
  check exact — the additions would be what the script wove in,
  nothing else.

  evidence: the boundary is stated in the requirement's own text rather than discovered later.

  script that would decide it: the queued `routine-change-sync`, which turns the carry rule from containment into equality.
