# Release record: v0.13.0

Compared against v0.12.0. The range is the three merges in
`v0.12.0..HEAD`. This is not a feature release and the entries below
do not pretend otherwise: it is the release where the project's own
memory stopped depending on one container staying alive, and where
one refactor got its safety net before the refactor.

## Caffeine

- **The standing queue outlives the session that holds it.** The work
  queue lived only in a session's task list, so a reset would have
  cost the whole thing. `BACKLOG.md` now carries the queued scripts
  and gates, the contract refinements whose evidence is still
  waiting, the proving-ground work, and the operator's standing
  rulings — each item naming its evidence or its earning condition
  rather than promising (#111).

  evidence: six of the seven queued items cite a measurement or name what would settle them, and the seventh names only its provenance — an overstatement in this very entry, caught by this record's own spot-check before publishing, which is the first time the sampled re-run has found a false claim rather than confirming one.

  lives in: `BACKLOG.md`

- **The example app can be rebuilt from the repository.** Nine commits
  of everything the loop has ever produced existed only in one
  container, on a repository with no remote — including the seal fix
  the analyst's own refutation found. Its full history now ships as a
  patch, verified by reconstruction rather than assertion (#112).

  evidence: applied into an empty repository the patch rebuilds all nine commits, `diff -r` against the live app finds nothing, and the app's suite closes at 49 runs, 194 assertions, 0 failures; the file was scanned against `lib/sensitive.sh` with zero hits before it was committed.

  lives in: `evidence/example-history.patch`

- **The example speaks in its own voice.** Five of those nine commits
  carried the harness's default author, which would have shipped in
  every future patch as the tooling's history rather than the app's.
  All nine were rewritten to the app's identity with content,
  messages and author dates untouched (#112).

  evidence: the regenerated patch rebuilds byte-for-byte identical with one author and the suite green; the archived tickets' `Grounded-at:` anchors were deliberately left naming the pre-rewrite chain, because an anchor records what HEAD actually was at grounding time and rewriting it would falsify the record — the old chain is pinned by a tag and every archived anchor still resolves through it.

  lives in: `evidence/example-history.patch`, the app's own history

- **A refactor got its net before the refactor.** `bin/routine-retro`
  is about to have two derivations lifted into `lib/awk/`, and
  nothing would have noticed a number moving. A fixture corpus — two
  apps, a colliding ticket id, twelve event kinds, several failures,
  one resolved blocked line and two unresolved — is rendered by the
  untouched retro and diffed byte for byte by the suite (#113).

  evidence: the guard was proven able to fail before being trusted — appending one `gate.developer` failure to the fixture moved `runs=3 fails=1` to `runs=4 fails=2` and the test went red on the diff, then the fixture was restored byte-identical and the suite returned green at 518.

  lives in: `test/retro.bats`, `test/fixtures/retro/`

- **A question about leaving bash was answered by measurement.** macOS
  dialect pain and a ten-minute suite elsewhere raised the idea of
  porting the harness. Three beliefs were refuted before any of it
  became a plan: a local daemon saves 0.9 ms and costs test
  isolation; JavaScript starts in about 30 ms where a whole routine
  script runs in 12 ms, and compiling it does not help because the
  runtime still boots inside the binary; and awk is already as fast
  as Go or Rust, so portability — not speed — is the only honest
  argument for compiling (#113).

  evidence: the same derivation implemented in four languages over 1,176 timestamps from the live corpus, twenty runs each, with launch costs measured separately; the case study records the tables, the framework comparison, the conversion shape of the existing suite, and the earning condition that the macOS failure be reproduced and named before any port begins.

  lives in: `BACKLOG.md`

## Gate

- **The record survives the machine; the run evidence still does
  not.** The backlog, the design and the example app now live in git,
  but `runs/` remains gitignored, so the telemetry every render is
  computed from is still one container away from gone. The designed
  answer — a release's evidence directory carrying the telemetry of
  the tickets that concluded in its window — is specified in the
  backlog and unbuilt.

  evidence: `git ls-files runs/` names exactly one marker file, while the live corpus holds 1,132 telemetry lines across eleven files.

  script that would decide it: the queued evidence-directory change, and `routine-example` as its reader — a format with no reader is unproven.

- **A change is parked mid-flight, and only a document says so.** One
  of seventeen tasks is done on `add-run-timeline`; the proposal sits
  on main unsynced and unarchived, which is what a parked change
  should look like, but nothing mechanical distinguishes parked from
  forgotten. A stale in-flight change would look identical.

  evidence: `openspec/changes/add-run-timeline/tasks.md` carries one ticked box and sixteen open ones; the parking note that explains it is prose in `BACKLOG.md`.

  script that would decide it: none yet — the earning condition is a second change sitting unfinished long enough that the two become confusable.

- **The stale render shipped again.** `evidence/retro.txt` still
  reports what it reported on 2026-08-14. The golden fixture that
  landed this release pins the retro's *behaviour*, not the
  freshness of its committed render, and the freshness gate remains
  designed rather than built.

  evidence: the committed render reports `gate.developer runs=4 fails=2`; the live corpus reports `runs=28 fails=3`.

  script that would decide it: the queued freshness gate — the release refuses a render it did not just regenerate.
